### ABSA NextGen Wealth Studio

## Overview

ABSA NextGen Wealth Studio is a financial planning and wealth management prototype designed to help young professionals and graduates make informed financial decisions as they enter higher earning stages of their careers.

The platform provides users with a personalised financial dashboard that enables them to track spending, monitor financial goals, understand investment pathways, and build long-term wealth strategies. The project was designed around the challenges many graduates face when transitioning from student life to financial independence, often without sufficient financial literacy or access to personalised guidance.

This project combines user-centred design principles with modern front-end development practices to create an engaging and accessible financial management experience.

## Problem Statement
Many young professionals begin earning salaries without a clear understanding of budgeting, investing, debt management, or long-term wealth creation. Financial products can be overwhelming, and traditional banking platforms often focus on transactions rather than financial education and planning.

ABSA NextGen Wealth Studio was developed as a concept solution that empowers users to:
* Understand their current financial position
* Track spending habits
* Set and monitor financial goals
* Explore investment opportunities
* Receive personalised financial insights
* Build sustainable financial habits for long-term success

## Key Features

Personalised Financial Dashboard
Provides users with a clear overview of their financial health through an intuitive and accessible interface.

Spending Analysis
Tracks spending patterns across different categories, helping users identify trends and opportunities for improvement.

Goal Tracking
Allows users to create, monitor, and update financial goals while visualising progress over time.

Investment Pathways
Introduces users to potential investment journeys aligned with their financial objectives and life stages.

Financial Insights
Generates contextual insights based on user financial data to encourage informed decision-making.

Interactive Onboarding
Guides users through profile setup and financial information capture to create a tailored experience.

Data Visualisation
Uses charts, progress indicators, and dashboard components to present financial information in a meaningful and engaging way.

## Installation
Clone the repository:
```bash
git clone https://github.com/JvTayla/absaNextGenWealtthStudio.git
```
Navigate to the project folder:
```bash
cd absaNextGenWealtthStudio
```
Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
